# Horizon Setup & Run Guide

### 1. Prerequisites (Databases)
Ensure your core infrastructure is actively running:
- **MongoDB**: (Cloud Atlas or Local at `mongodb://localhost:27017`)
- **Redis Server**: (Local at `redis://localhost:6379`, typically via WSL/Docker)
- **Neo4j Desktop**: (Start your active database, ensure it is listening on `bolt://localhost:7687`)

### 2. Backend Server (FastAPI)
Open Terminal 1, navigate to the `backend/` directory, and start the API:
```bash
cd backend
.\venv\Scripts\Activate
python -m uvicorn main:app --reload
```

### 3. Frontend Application (React/Vite)
Open Terminal 2, navigate to the `interface/` directory, and boot the client:
```bash
cd interface
npm run dev
```

### 4. Initialize Demo Profile (First Time Only)
If you want to enable the one-click "Demo" button in the Navbar for recruiters/founders, you must inject the synthetic "Alex Chen" profile into the database. 
Open Terminal 3 in the `backend/` directory:
```bash
cd backend
.\venv\Scripts\Activate
python seed_demo.py
```
